# RideSchedule2.0

A ride scheduling and service management system where riders can post daily, weekly, or monthly ride schedules, and drivers can manage ride requests. Includes service-based rides (parcel, pharmacy), fare estimation, ratings, and notifications.

🔗 **Live Demo:** https://ride-schedule.onrender.com/
> Note: hosted on Render's free tier — the first load may take ~20–30 seconds while the server wakes up.

---

## Features

- **Ride Scheduling** — Riders can post daily, weekly, or monthly ride schedules.
- **Driver Management** — Drivers can view and manage incoming ride requests.
- **Service-Based Rides** — Support for parcel delivery and pharmacy-related rides.
- **Fare Estimation** — Automated fare estimation through CostBot.
- **Ratings & Notifications** — Riders and drivers can rate each other, with built-in notification support.
- **User Accounts** — Separate account handling for riders and drivers.

---

## Tech Stack

- **Backend:** Django (Python)
- **Frontend:** HTML, CSS, JavaScript, Bootstrap
- **Deployment:** Render
